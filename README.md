# MineFinder

_MineFinder is a modern take on the classic Minesweeper puzzle game, built using SwiftUI for iOS and macOS. Test your logic and strategy as you uncover tiles and avoid hidden bombs!_

## Features

- 🎮 **Classic Minesweeper Gameplay:** Open tiles, avoid bombs, and mark suspected danger zones.
- 🏆 **Multiple Difficulty Levels:** Choose from Beginner, Medium, or Expert board sizes and bomb densities.
- 📊 **Score Tracking:** Your performance is measured by your speed and efficiency!
- ⏱ **In-Game Timer:** See how fast you can clear the board.
- ⚙️ **Customizable Settings:** Adjust rows, columns, and difficulty directly from the app.
- 🎨 **Clean SwiftUI Design:** Responsive layout and smooth animations.

## Getting Started

### Prerequisites

- Xcode 15 or later
- Swift 5.9+
- iOS 17+ or macOS 14+

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/manuglez/BoomFinder.git
   ```

2. Open the project in Xcode:

   ```sh
   open BoomFinder.xcodeproj
   ```

### Gameplay

* Tap a tile to reveal it. If it's a bomb, the game ends!
* Long-press a tile to mark it as containing a bomb (🚩).
* The number on a tile indicates how many bombs are adjacent to it.
* Clear all non-bomb tiles to win.
* Use the settings screen (top-right slider icon) to adjust the board size or difficulty.
